# Interactive-Sales-Dashboard-Excel

Interactive Sales Performance Dashboard built in Microsoft Excel using Pivot Tables, Slicers, and Dynamic Charts to analyze revenue trends, regional sales, and top-performing products.

## 📊 Dashboard Preview
![Sales Dashboard](Excel%20Project%20Dashboard%201.png)

## 🎯 Project Objective
The goal of this project is to transform raw sales data into an interactive, easy-to-understand visual report that helps stakeholders track key performance indicators (KPIs) and make data-driven business decisions.

## ✨ Key Features
- **Interactive Slicers:** Filter data dynamically by Region, Year, Product Category, or Salesperson.
- **KPI Summary Cards:** Quick overview of Total Revenue, Total Profit, Profit Margin, and Units Sold.
- **Dynamic Charts:** 
  - Monthly/Yearly Revenue Trend (Line/Area Chart)
  - Regional Sales Performance (Bar/Map Chart)
  - Top-Performing Products & Categories (Column/Pie Chart)
- **Automated Updates:** Built on structured Excel Tables and Pivot Tables so the dashboard updates automatically when new data is added.

## 🛠️ Tools & Techniques Used
- **Microsoft Excel**
- **Pivot Tables & Pivot Charts**
- **Slicers & Timelines**
- **Excel Formulas** (SUMIFS, XLOOKUP/VLOOKUP, IF, etc.)
- **Data Cleaning & Formatting**

## 🚀 How to Use
1. Download the Excel workbook (`.xlsx`) from this repository.
2. Open the file in Microsoft Excel (Enable Macros/Editing if prompted).
3. Use the **Slicers** on the dashboard sheet to filter metrics based on your requirements.
4. To update with new data, paste the records into the Data sheet and click **Data > Refresh All**.
